# Self-hosted fonts

These files are served by `next/font/local` (see `../layout.tsx`) so the production build does not
fetch Google Fonts. All three families are licensed under the SIL Open Font License 1.1
(https://openfontlicense.org), which permits redistribution and embedding with this notice.
